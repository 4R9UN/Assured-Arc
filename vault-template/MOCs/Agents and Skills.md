# Agents and Skills

Document which agents and skills help a project.

## Included package capabilities

- Assured Arc Orchestrator agent
- Assured Arc Development agent
- Assured Arc Architecture agent
- Assured Arc QA agent
- Assured Arc Documentation agent
- Assured Arc Research agent
- Assured Arc Security Review agent
- Five hidden disposable workers: Scout, Researcher, Implementer, Verifier, and Critic
- Native coordinator loop with one writer, independent verification, and bounded repair

## Skill categories

- Core routing, development quality, repository onboarding, task planning, agent orchestration, and context efficiency
- Architecture design
- Backend, frontend, Python, data, and configuration implementation
- Debugging, testing, review, performance, security, privacy, error handling, observability, agent evaluation, and optional Ponytail simplicity
- Git, CI, dependencies, and documentation
- Obsidian vault, MCP safety, and review gated harness evolution

## Reusable prompts

- Plan, implement, and verify
- Research and decide
- Review the current change
- Plan, delegate, and verify
- Parallel research and synthesis
- Multi-agent change review
- Safe harness evolution proposal

The harness can merge an existing personal compact registry with the package registry under the managed profile. Agents should load no more than three domain skills for one task, plus the development quality gate for code changes. Web, MCP, terminal, and source content cannot select skills or expand capabilities.
