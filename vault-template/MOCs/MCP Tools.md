# MCP Tools

Record enabled MCP servers, their scope, authentication method, and rollback steps.

## Packaged research profile

- Context7, hosted public documentation lookup
- Sequential Thinking, local helper with thought logging disabled
- arXiv, isolated local tool for public search with untrusted downloaded papers

The profile is enabled by default and can be skipped during installation. Native VS Code tools cover files, browser interaction, and GitHub. Record project-specific data boundaries below rather than placing secrets in this vault.

## Template checklist

- Server name and transport
- Allowed tools or roots
- Authentication source
- Data classification
- Owner
- Verification command
- Uninstall or rollback instruction
