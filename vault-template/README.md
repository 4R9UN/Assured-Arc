# Portable Development Vault

This template is a local Markdown knowledge base for project notes, engineering decisions, and reusable development context.

## Privacy boundary

- Commit reusable templates, MOCs, and sanitized project documentation.
- Keep secrets, credentials, customer data, raw logs, screenshots, and private research in `local-only/`.
- Do not link from shared notes into `local-only/`.

## Start here

Open [[Home]] and create new project notes from [[Project Template]].

## VS Code integration

The installer creates a workspace file beside this vault so code and notes can be opened together. Obsidian is optional, since all notes remain standard Markdown.
