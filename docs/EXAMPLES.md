# Usage Examples

## Run a complex task through the global harness

1. Select **Assured Arc Orchestrator**.
2. Describe the outcome, constraints, and required evidence.
3. The coordinator creates an acceptance contract and selects up to three skills.
4. Independent read only discovery can run in parallel.
5. One disposable implementer makes scoped changes.
6. A separate verifier checks literal acceptance criteria.
7. The loop repairs at most twice and returns one consolidated result.

For a simple read only question, the orchestrator should answer directly without a worker.

## Research with isolated evidence streams

Run `/parallel-research-synthesize` with a question and source constraints. The coordinator can use up to three disposable researchers or scouts. Each returns facts, author reported claims, inferences, unknowns, URLs, and dates. A critic can challenge conflicting evidence before synthesis.

## Review without anchoring

Run `/multi-agent-change-review`. Independent critics examine correctness and regression, security and privacy, and reliability and complexity. The coordinator deduplicates findings by root cause. Critics cannot edit or execute.

## Implement a focused feature

1. Select **Assured Arc Development** in VS Code.
2. Ask: “Add a parser for this configuration field and test invalid input.”
3. The agent should inspect existing config and tests, make a small change, and run focused validation.

## Create durable project context

1. Open the generated vault.
2. Create a note from **Project Template**.
3. Record outcome, measurable success criteria, selected skills, and validation evidence.
4. Link architecture and decision notes through wikilinks.

## Review a marketplace extension

1. Select **Assured Arc Research**.
2. Provide the extension URL or identifier.
3. Request an assessment of license, maintenance, permissions, network behavior, and privacy implications.
4. Enable only after a human reviews the recommendation.

## Add a new MCP template

1. Use **Assured Arc Research** to inspect the public server source and license.
2. Use **Assured Arc MCP Safety** to define transport, auth, scope, and rollback.
3. Add a secret free template under `mcp/`.
4. Update schema, documentation, and tests.
5. Use **Assured Arc Security Review** before release.

## Troubleshoot an install

Run the dry run again, inspect the profile state and backup directory, then use the uninstall script if required.

## Propose a harness improvement

Run `/evolve-harness-safely` only after the same failure appears in multiple sanitized scenarios. Produce one change contract, apply it in an isolated worktree and VS Code profile, compare baseline and candidate scenarios, and ask a human to keep, revise, or revert it. Never promote a daily agent self modification directly into global settings.
